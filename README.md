# Far Ends

This repository is set up as a minimal GitHub Pages blog powered by Jekyll with the supported `minima` theme. For a personal site, the GitHub repository should be named `hectormorag.github.io`.

## Creating new posts

Add new posts in the `_posts/` directory using this filename format:

```text
YYYY-MM-DD-title.md
```

Each post should include Jekyll front matter, for example:

```markdown
---
layout: post
title: "My New Post"
date: 2026-03-29
---

Write your post content here.
```

## GitHub Pages deployment

In the repository settings, GitHub Pages should be configured to deploy from:

- Branch: `main`
- Folder: `/ (root)`
